Mode de jeu

Tu peux encore changer le mode de jeu tant que la partie n'a pas commencé.

Les modes "Qui est-ce ?" et "Demi-Cercle" se jouent uniquement à 2 : quitte-les tant qu'un 3e joueur est dans le lobby.

Choisis les générations

Sélectionne une ou plusieurs générations de Pokémon qui apparaîtront en jeu.

Mode de grille

Choisis la taille de la grille de jeu.

Nombre de manches

Choisis le nombre total de manches. Pour garantir l'équité, seules les valeurs faisant jouer chaque joueur le même nombre de fois sont proposées.

Sens du jeu

Choisis comment les joueurs devront deviner à chaque manche.

Mode Demi-Cercle : 10 Pokémon aléatoires seront tirés (un par round) parmi les générations choisies.

Mode Devin'Mon : chaque joueur sera le Guide 2 fois. Assure-toi d'avoir sélectionné assez de générations.

Mode Dessine-moi un Pokémon : chaque joueur sera le Dessinateur 2 fois. Assure-toi d'avoir sélectionné assez de générations.

Mode Pokédex Target : chaque joueur joue 2 manches. Assure-toi d'avoir sélectionné assez de générations.

Mode La Stat la plus haute : 10 manches, tout le monde répond à chaque manche. Assure-toi d'avoir sélectionné assez de générations.
